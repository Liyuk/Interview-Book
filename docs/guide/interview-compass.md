# Interview Compass

[Interview Compass](https://liyuk.github.io/interview-compass/) 是一份面向候选人、面试官和管理者的双语面试与晋升参考。它帮助你理解岗位目标、问题意图和可观察的证据，适合把本书中的知识准备延伸到面试表达、面试设计或晋升复盘。

## 怎么开始

1. 先按目标选择路径：外部面试、校招、面试官设计、晋升或自我复盘。
2. 选择工程方向和职责阶段，浏览对应的问题；不确定时可以先看完整问题库。
3. 阅读每道题的考察意图和观察信号，用自己的具体经历说明背景、职责、判断、行动和结果。
4. 面试官可以用问题意图和上下文追问来校准判断，不把信号当成机械打分表。

它提供分析思路，不提供标准答案，也不会自动给人打分。题目页可以生成分析提示词，供你自行复制到选择的外部 AI 工具中。
